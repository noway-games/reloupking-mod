# Changelog

## [1.0.0]

**20 teintes de cheveux prédéfinies** :
  - Choix parmi 20 teintes pour les cheveux et les sourcils.

**Couleur personnalisée via code Hexadécimal** :
  - Possibilité de coller n'importe quelle couleur personnalisée (`#RRGGBB`) directement depuis le presse-papier avec la touche **`K`**.
  - Verrouillage automatique du scroll de la molette lorsqu'une couleur personnalisée est active pour éviter les changements involontaires.
  - Message d'erreur si code hexadécimal invalide

**Réinitialisation Rapide (`L`)** :
  - Touche **`L`** pour réinitialiser instantanément à la couleur par défaut et déverrouiller la molette.

**HUD Intégré au Miroir** :
  - Interface avec pastille de couleur en temps réel et rappel des commandes.

**Synchronisation Multijoueur** :
  - Synchro en temps réel auprès de tous les joueurs
