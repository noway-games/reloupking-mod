# ReLoupKing

Mod de personnalisation pour **Lycans** permettant de changer la couleur de vos cheveux (et sourcils).

![Changement de couleur](https://raw.githubusercontent.com/noway-games/reloupking-mod/main/change-colors.png)

## Fonctionnalités

- **20 couleurs prédéfinies** au choix.
- **Couleur personnalisée (Hex)** : appliquez n'importe quelle couleur avec un code hexadécimal (ex : `#FF5500`).
- **Synchronisé en multijoueur** : votre couleur est visible par tous les autres joueurs.
- **Sauvegarde automatique** d'une partie à l'autre.

![Couleur Hexadécimale](https://raw.githubusercontent.com/noway-games/reloupking-mod/main/hex-color.png)

## Commandes

Dans le lobby, appuyez sur **`Ctrl`** pour personnaliser son apparence:

| Touche | Action |
| :--- | :--- |
| **`Molette`** | Changer de couleur parmi les 20 teintes |
| **`K`** | Coller une couleur hexadécimale depuis le presse-papier (ex : `#FF5500`) |
| **`L`** | Réinitialiser à la couleur par défaut |
| **`Ctrl`** | Quitter la personnalisation |

*(Lorsqu'une couleur personnalisée est active, la molette est verrouillée ; utilisez `L` pour la réinitialiser).*
