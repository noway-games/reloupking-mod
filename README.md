# ReLoupKing

Mod de personnalisation pour **Lycans** : couleur des cheveux, de la peau, du pantalon (ou short) et des bottes.

![Changement de couleur](https://raw.githubusercontent.com/noway-games/reloupking-mod/2.0.0/change-colors.png)

## Fonctionnalités

- **Cheveux, peau, pantalon, bottes** : 20 teintes prédéfinies chacun.
- **Coupe** : pantalon ou short.
- **Couleur personnalisée (Hex)** : n'importe quelle couleur via un code hexadécimal (ex : `#FF5500`).
- **Synchronisé en multijoueur** : votre apparence est visible par tous les joueurs équipés du mod.
- **Sauvegarde automatique** d'une partie à l'autre.
- Compatible avec **LycansNewRoles** (illusions, camouflage, leurre du magicien).

![Couleur Hexadécimale](https://raw.githubusercontent.com/noway-games/reloupking-mod/2.0.0/hex-color.png)

## Commandes

Dans le lobby, appuyez sur **`Ctrl`** pour ouvrir le miroir de personnalisation :

| Touche | Action |
| :--- | :--- |
| **`J`** | Catégorie suivante (Cheveux → Peau → Coupe → Pantalon → Bottes) |
| **`Molette`** | Option ou teinte suivante / précédente |
| **`K`** | Coller une couleur hexadécimale depuis le presse-papier (ex : `#FF5500`) |
| **`L`** | Réinitialiser toute l'apparence |
| **`Ctrl`** | Quitter la personnalisation |

*(Lorsqu'une couleur personnalisée est active, la molette est verrouillée pour cette catégorie ; utilisez `L` pour réinitialiser.)*
